# МойДом — Цифровая среда управления многоквартирным домом в MAX

## 1. Назначение решения
«МойДом» — цифровой сервис в мессенджере MAX для жителей МКД, ТСЖ и управляющих организаций в рамках трека «Умный город». Решение объединяет ключевые бытовые процессы: прозрачную работу с квитанцией ЖКУ (ЕПД), контроль инженерных коммуникаций, онлайн-видеонаблюдение подъездов, подачу заявок с фотофиксацией, защищённый чат дома и юридически прозрачные опросы собственников.

## 2. Основной пользовательский сценарий
1. Вход и идентификация пользователя в квартире МКД.
2. Просмотр ЕПД, прозрачный расчёт по счётчикам и нормативам, симуляция мгновенной оплаты через СБП с фиксацией электронного чека.
3. Мониторинг аварийного статуса коммуникаций и онлайн-видеонаблюдения подъездов (1-5 подъезды).
4. Оформление диспетчерской заявки по клику на центральную кнопку «+» с возможностью прикрепления фото.
5. Общение в домовом чате с официальными объявлениями ТСЖ и защитой от удаления чужих сообщений.
6. Участие в голосованиях: невозможность сменить голос без предварительной отмены, фиксация итогов завершённых голосований (13 за, 7 против).
7. Быстрый возврат к эталонному состоянию через кнопку сброса на верхнем тулбаре.

## 3. Состав и архитектура решения
- `frontend/` — легковесный клиент React 19 + Vite с мобильным адаптивным интерфейсом и CSS-анимациями.
- `backend/` — высокопроизводительный REST API на FastAPI (Python 3.11).
- `docker-compose.yml` — единая конфигурация запуска сервисов.
- `DATA-API.yaml` — формализованный контракт тестирования API.

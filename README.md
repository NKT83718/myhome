# МойДом — мини‑приложение для ЖКХ и управления домом

## Назначение решения
«МойДом» — мини‑приложение в мессенджере MAX для жителей МКД. В MVP реализованы:
- «Квитанция»: прозрачная квитанция (ЕПД) с возможностью добавлять услуги (по счётчику / не по счётчику) и оплачивать (в MVP — симуляция оплаты с формированием чека).
- «Дом»: инфощит со статусами коммуникаций дома и вывозом ТКО.
- «Заявки»: диспетчерская — создание заявок с прикреплением фото, отмена.
- «Чат»: домовой чат (сообщения, удаление своих сообщений).
- «Опросы»: голосования жильцов (голос, изменение голоса, отмена).

Продукт разработан для трека «Умный город» (управление домом и жилищные вопросы).

---

## Основной пользовательский сценарий (MVP)
1) Пользователь открывает мини‑приложение «МойДом».
2) Вкладка «Квитанция»:
   - видит автоподтянутые фиксированные начисления (редактирование запрещено);
   - добавляет услуги, которые зависят от пользователя (по счётчику / не по счётчику);
   - вводит текущие показания (для счётчика) или объём (для не счётчика);
   - оплачивает → квитанция становится «Оплачено», сумма = 0, строки квитанции скрываются, повторно оплатить нельзя; отображается «ЧЕК …».
3) Вкладка «Дом»: видит статусы коммуникаций (электроснабжение, лифт, ХВС, ГВС, газ, отопление) и статус/график вывоза ТКО.
4) Вкладка «Заявки»: создаёт заявку (с фото или без), видит её в списке, может отменить.
5) Вкладка «Опросы»: голосует, меняет голос или отменяет, видит обновление количества голосов.

## Состав и архитектура решения
### Компоненты
- `frontend/` — мини‑приложение (React + Vite), UI под вертикальный телефон (контейнер max-width).
- `backend/` — собственный API (FastAPI):
  - хранение данных в памяти (для воспроизводимости без БД);
  - выдача данных квитанции/дома/опросов;
  - создание заявок с загрузкой фото (сохранение в `backend/uploads/`);
  - формирование «чека» при оплате (в MVP симуляция).

### Взаимодействие
Мини‑приложение обращается к API:
- `GET /api/bill`, `POST /api/bill/items`, `PATCH/DELETE /api/bill/items/{id}`, `POST /api/bill/pay`
- `GET /api/house`
- `GET /api/requests`, `POST /api/requests`, `DELETE /api/requests/{id}`
- `GET /api/chat`, `POST /api/chat`, `DELETE /api/chat/{id}`
- `GET /api/polls`, `POST /api/polls/{id}/vote`, `DELETE /api/polls/{id}/vote`

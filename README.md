# МойДом — Цифровой сервис управления МКД в мессенджере MAX

## 1. Назначение решения
«МойДом» — цифровое решение для жителей многоквартирных домов, ТСЖ и управляющих организаций в рамках трека «Умный город». Сервис функционирует как мини-приложение внутри мессенджера MAX и решает задачи прозрачного расчёта начислений ЖКУ, мониторинга домовых коммуникаций, просмотра камер видеонаблюдения подъездов, подачи диспетчерских заявок с фотофиксацией, защищённого общения в домовом чате и проведения юридически легитимных голосований собственников.

## 2. Основной пользовательский сценарий
1. Вход жителя в мини-приложение в мессенджере MAX (лицевой счёт квартиры 8, дом 8).
2. Просмотр единого платёжного документа (ЕПД), расчёт услуг по счётчикам и нормативам, моментальная тестовая оплата через СБП с получением номера чека.
3. Контроль статуса инженерных систем дома и онлайн-просмотр видеокамер подъездов с 1 по 5.
4. Создание заявки в аварийно-диспетчерскую службу через центральную кнопку-плюс с прикреплением фотографии.
5. Коммуникация в общедомовом чате с официальными объявлениями ТСЖ и невозможностью удаления чужих сообщений.
6. Участие в опросах дома: невозможность изменить голос без предварительной отмены текущего голоса, фиксация итогов завершённых голосований (13 на 7).
7. Сброс состояния приложения в исходное нажатием верхней левой кнопки обновления.

## 3. Состав и архитектура решения
- `frontend/`: клиентское SPA на React 19 + Vite с мобильной адаптивной версткой под экран смартфона и плавными анимациями смены экранов.
- `backend/`: REST API на базе Python 3.11 и FastAPI.
- `docker-compose.yml`: файл единой контейнеризации и оркестрации клиентской и серверной части.
- `DATA-API.yaml`: формализованная спецификация тестирования API-методов для жюри.
- `bot.py`: фоновый процесс бота MAX, открывающий мини-приложение внутри мессенджера без перехода в сторонние браузеры.
